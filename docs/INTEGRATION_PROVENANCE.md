# Integration provenance

Archis Optical Tracker 2.0 uses Archis1 commit `06022f1` as the product baseline and selectively ports engineering ideas from Qlyraxis commit `2514c5d` and AstraTrack commit `856b483f89f33a77b61c8735f48df6a79a75c994`. The histories were not merged and no force push was used.

Retained from Archis1: the PyQt/Fluent desktop experience, scene renderer, target catalogue, preset names, NanoSpot ONNX model, React presentation site, and individual algorithm demonstrations.

Integrated or reworked from Qlyraxis: immutable frame/truth/detection/result contracts, fixed-step seeded scenarios, full-frame robust acquisition, explicit tracking states, candidate evidence fusion, CodeLock identity, bounded control, truth-isolated evaluation, external media and sidecars, stress/comparison commands, report exports, and packaging structure.

Reviewed and independently strengthened from AstraTrack concepts: Joseph-form Kalman covariance correction, configurable catastrophic-jump rejection, latency-compensated kinematic aimpoints, and deterministic burst-loss testing with an isolated RNG stream. AstraTrack's DearPyGui interface, HSV detector, model-less AI fallback, heuristic uncertainty expansion, periodic blackout function, and process-randomized hash seeding were not imported.

The merged implementation is original integration work in the Archis namespace. Qlyraxis and AstraTrack remain provenance references; published benchmark values were regenerated by the merged engine and are not copied from any baseline or reference repository.
